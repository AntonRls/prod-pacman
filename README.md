# PROD — Лотти против багов

Браузерная аркада на HTML, CSS и JavaScript в пиксельном стиле PROD. Лотти собирает фиксы и убегает от багов, а чип отладки на время меняет их ролями.

[Играть онлайн](https://prod-lotti-debug-arcade.anton-piskorskiy.chatgpt.site)

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются. Можно также разместить содержимое репозитория на любом статическом хостинге.

## Управление

- Стрелки или WASD — движение.
- Свайпы и кнопки со стрелками слева — управление на телефоне.
- Пробел — пауза, R — новая попытка, F — полный экран.

После попытки можно ввести имя или выбрать случайный мемный ник. Таблица лидеров с датой и временем хранится в браузере на устройстве через `localStorage`.

## Файлы

- `index.html` — страница и окна интерфейса.
- `styles.css` — оформление и адаптация под экран.
- `game.js` — игровая логика, управление и рекорды.
- `pixel-art.js` — спрайты и пиксельные иконки.
- `assets/` — изображения, шрифт Tiny5 и его лицензия.
- `tests/leaderboard.cjs` — проверки таблицы лидеров.

## Проверки

Для запуска проверок нужен Node.js:

```sh
node --check game.js
node --check pixel-art.js
node tests/leaderboard.cjs
```

Шрифт Tiny5 распространяется по SIL Open Font License 1.1; текст лицензии находится в `assets/Tiny5-LICENSE.txt`.
