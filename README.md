# PROD — Лотти против багов

Браузерная аркада на HTML, CSS и JavaScript в пиксельном стиле PROD. Лотти собирает фиксы и убегает от багов, а чип отладки на время меняет их ролями.

[Играть онлайн](https://antonrls.github.io/prod-pacman/)

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются. Можно также разместить содержимое репозитория на любом статическом хостинге.

GitHub Pages публикует игру из корня ветки `main`. Изменения, отправленные в эту ветку, автоматически появляются на сайте после завершения публикации.

## Управление

- Стрелки или WASD — движение.
- Свайпы и кнопки со стрелками слева — управление на телефоне.
- Пробел — пауза, R — новая попытка, F — полный экран.

После попытки можно ввести имя или выбрать случайный мемный ник. Таблица лидеров с датой и временем хранится в браузере на устройстве через `localStorage`.

## Характеры багов

- Красный Блинки преследует Лотти и ускоряется, когда на поле остаётся мало фиксов.
- Розовый Пинки целится на четыре клетки впереди Лотти.
- Голубой Инки вычисляет цель по позиции Блинки и точке на две клетки впереди Лотти.
- Оранжевый Клайд преследует издалека и уходит в свой угол на расстоянии меньше восьми клеток.

Используются цели и порядок выбора поворотов оригинального Pac-Man, включая особенность при движении вверх. Погоня чередуется с уходом в углы по расписанию первого уровня: 7/20/7/20/5/20/5 секунд, затем постоянная погоня. Смена режима разворачивает багов. Чип отладки на восемь секунд приостанавливает это расписание: баги синеют, замедляются и выбирают повороты случайно. Пойманный баг возвращается домой в виде глаз и снова вступает в игру.

Это адаптация поведения для случайно создаваемых лабиринтов: старт и возвращение происходят в углах вместо общего домика, в тупиках разрешён разворот. Пороги ускорения Блинки масштабируются под число фиксов; скорость игры и длительность чипа сохранены для этой версии.

## Файлы

- `index.html` — страница и окна интерфейса.
- `styles.css` — оформление и адаптация под экран.
- `game.js` — игровая логика, управление и рекорды.
- `pixel-art.js` — спрайты и пиксельные иконки.
- `assets/` — изображения, шрифт Tiny5 и его лицензия.
- `tests/leaderboard.cjs` — проверки таблицы лидеров.

## Проверки

Для запуска проверок нужен Node.js:

```sh
node --check game.js
node --check pixel-art.js
node tests/leaderboard.cjs
node tests/rendering.cjs
node tests/bugs.cjs
```

Шрифт Tiny5 распространяется по SIL Open Font License 1.1; текст лицензии находится в `assets/Tiny5-LICENSE.txt`.
